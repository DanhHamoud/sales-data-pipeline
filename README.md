Sales ETL vs ELT Data Pipeline & Data Warehouse
A comprehensive data engineering project comparing and implementing both ETL (Extract, Transform, Load) and ELT (Extract, Load, Transform) architectural pipelines using Python, SQLite, and MongoDB for advanced sales data analysis and reporting.

Tech Stack and Tools
Programming Language: Python

Relational Database: SQLite

NoSQL Database: MongoDB

Data Processing and Analysis: Pandas, NumPy

Core Concepts: Data Staging, Data Quality Validation, Currency Conversion, Data Warehousing

Pipeline Architecture and Workflow
This project demonstrates and compares two fundamental data processing paradigms:

ETL (Extract, Transform, Load): Extracts raw data, applies transformations and cleaning via Python programmatically, and then loads it into the target warehouse.

ELT (Extract, Load, Transform): Loads raw data directly into the database staging area first, leveraging database engine performance and indexing capabilities for downstream transformations.
